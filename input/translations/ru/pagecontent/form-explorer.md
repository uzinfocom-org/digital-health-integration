Каждую сопоставленную форму можно изучить здесь в трёх представлениях по образцу openEHR Clinical Knowledge Manager:

- Карта - разделы и поля формы на одном экране, с типом данных каждого поля.
- Разделы - таблица для каждого раздела со значением, путём FHIR, привязкой и списком ответов каждого поля.
- Дерево формы - поля в виде элементов ввода, при желании заполненных значениями из примера, с путями FHIR.

Выберите поле в любом представлении, чтобы увидеть его путь FHIR, кратность, привязку к терминологии, пример значения и список ответов. Представления строятся по странице сопоставления каждой формы, её профилю Composition и связанным с ними системам кодов и наборам значений, поэтому всегда соответствуют руководству. Основным описанием каждой формы остаётся её страница сопоставления.
