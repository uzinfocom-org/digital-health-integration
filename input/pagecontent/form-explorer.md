Every mapped form can be explored here in four views:

- Overview - what the form is, its document header, its sections and a count of its data elements.
- Data - every data element in a table, grouped by section, with its description and allowed values, and optionally its FHIR path.
- Mind map - the form's sections and data elements at a glance, with each element's data type. Select an element to see what it holds.
- Form preview - the data elements laid out as a form, optionally filled with the example values.

The views are generated from each form's mapping page, its Composition profile and the code systems and value sets these bind to, so they always match the guide. The mapping page stays the reference for each form.
